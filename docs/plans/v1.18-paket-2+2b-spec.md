## Paket 2 — Katalog-Refresh reparieren

### Problem (Review 2026-09-08, P1 + P2; Commit `60a128c`)

1. **Fehler zählen als Erfolg.** `CatalogRemoteDataSource` (`CatalogRemoteDataSource.swift:61`) mappt jeden HTTP-Status außer 200/304 auf `.skipped`. `EpisodeCatalog` behandelt `.skipped` gemeinsam mit `.notModified` (`EpisodeCatalog.swift:159`, `:193`, `:268`) und schreibt `lastCheckedAt = .now`. Ein 404/429/500/Timeout sieht damit aus wie ein geprüfter Katalog; der reguläre Refresh pausiert danach 6 h. Bei manueller Aktualisierung erscheint fälschlich „Aktive Kataloge wurden aktualisiert".
2. **Kein Teil-Erfolg.** `EpisodeCatalog` hat genau ein `lastRefreshError: String?`. In der parallelen `TaskGroup` (`EpisodeCatalog.swift:107`) gewinnt der letzte Schreiber. Es gibt keine Aggregation pro Quelle, keinen sichtbaren „3 von 5 aktualisiert"-Zustand.
3. **Versuch ≠ Erfolg.** `RemoteCatalogMetadata.lastCheckedAt` vermischt „zuletzt versucht" und „zuletzt erfolgreich".
4. **Kein Vordergrund-Refresh.** `EpisodeTrackerApp.swift:51` stößt bei `scenePhase == .active` nur die Cloud-Sync-Reparatur an. Der 6-h-Zeitraum ist eine Sperre, kein Hintergrundjob.
5. **An den Bootstrap gekoppelt.** `AppDataBootstrapper` ruft `refreshManagedCatalogsIfNeeded(ignoringThrottle: true)` inline und **`await`et** es (`AppDataBootstrapper.swift:83`, `:113`). Katalog-Netz-I/O liegt damit auf dem kritischen Startpfad; jeder Kaltstart erzwingt einen Manifest- + je-Katalog-Abruf.
6. **Dauerhafter Cache-Bypass.** `needsStreamingLinkRefresh` / `needsMarketLinkRefresh` (`EpisodeCatalog.swift:218`) setzen `requestMetadata = nil` (ETag verwerfen), solange nicht **jeder** Marktdienst mindestens einen Link hat. Für einen Nischenkatalog ist das evtl. nie erfüllt → jeder Refresh lädt voll. Plan §5: „Fehlende Streaming-Dienste sind kein Grund, bei jedem Abruf den Cache zu umgehen … Cache-Formatmigration über eine explizite Version steuern."

### Soll

- **Typisierte Ergebnisse.** `.skipped` entfällt; Fehler werden als eigener Fall mit Kategorie (HTTP-Status / Transport / kein-HTTP / Decoding) modelliert.
- **Aggregiertes Ergebnisobjekt.** `refreshManagedCatalogsIfNeeded` liefert ein `CatalogRefreshOutcome` mit einem `SourceResult` je Quelle (Manifest, Katalog, Bald-verfügbar). Teil-Erfolg ist deterministisch ablesbar. `lastRefreshError` wird daraus **abgeleitet**, ist nicht mehr die Quelle der Wahrheit.
- **Versuch/Erfolg getrennt.** `RemoteCatalogMetadata` bekommt optionales `lastAttemptAt` + `lastFailureKind`. Bei Fehlschlag bleiben `lastCheckedAt`, `eTag`, `lastModified` **unangetastet** und die Cache-Einträge erhalten → der 6-h-Cooldown startet nach einem Fehler nicht (Spiegelbild der Tested-Solutions-Regel „Stage zurücksetzen ⇒ jede daran hängende Frist zurücksetzen": ein Fehlschlag darf die Frist-Uhr nicht *vorstellen*).
- **Vom Bootstrap entkoppelt.** Bootstrap erledigt nur die lokalen Voraussetzungen gegen den vorhandenen Cache. Der Refresh läuft als eigener `Task` nach `AppDataBootstrapper.bootstrap(...)` und stößt danach `reconcileSpecialEpisodes` / `reconcileCatalogStyles` erneut an, damit ein frisch geladener Anthologie-Katalog ohne Neustart seinen Stil bekommt.
- **Gedrosselter Vordergrund-Refresh.** `scenePhase == .active` (ab der zweiten Aktivierung) stößt `refreshManagedCatalogsIfNeeded()` **ohne** `ignoringThrottle` an; `shouldRefresh` (6 h) gilt. Ein In-Flight-Guard führt gleichzeitige Vordergrund- und manuelle Abrufe zusammen (Review: „parallele identische Abrufe zusammenführen").
- **Cache-Formatversion.** Der einmalige Link-Backfill greift nur, wenn die gespeicherte Formatversion < aktuell ist, nicht bei „irgendein Marktdienst hat keinen Link". „Ein Werk muss nicht auf allen Diensten vorhanden sein."

### Abnahme (Prüf-Spalte Paket 2)

Netzwerkfehler-, Race-, Offline-Tests. Verifiziert: **200, 304, 404, 429, 500, Timeout, ungültiges JSON**; Teil-Erfolg (eine von mehreren Quellen scheitert); Coalescing zweier gleichzeitiger Refreshes zu einem Fetch-Satz; Bootstrap kehrt zurück, ohne auf einen Fetch zu warten; kein „aktualisiert"-Erfolg, wenn alle Quellen scheitern; `testIgnoringThrottleRefetchesEvenWhenRecentlyChecked` bleibt grün.

## Paket 2b — Anthologie-Pfad schärfen

### Problem

1. **Invariante nur im Bearbeiten-Pfad.** „`style: anthology` ⇒ jede Folge `kind: special`" wird nur über `EpisodeEditDraft.resolvedIsSpecial` (`EpisodeEditDraft.swift:48`) im manuellen Speichern durchgesetzt. Beim Katalog-Import (`EpisodeCatalog.refreshManagedCatalogIfNeeded`, `.refreshManagedCatalog`, `importCatalog(data:into:)`) behalten Einträge das im JSON deklarierte `kind` (Default `.regular`), unabhängig vom `style` der Quelle. `CatalogLibraryMatcher`, `SpecialEpisodeReconciler` und die Snapshot-/Delta-Bildung verlassen sich auf konsistente Daten. Der FR-Katalog wäre der erste echte Anthologie-Katalog in Produktion.
2. **Nicht-Streaming-Links fallen raus.** `CatalogEntry.links` wird über `StreamingService.rawValue` gelesen (`StreamingService.swift:57`, `catalogURL(from:)`). Eine France-Culture-/Radio-France-/Studio-URL hat keinen passenden `StreamingService`-Case → sie erscheint nie in der Detailansicht. `StreamingLinkResolver.resolve(for:)` kennt nur Streaming-Dienste.

### Soll

- **`kind` beim Import aus `style` ableiten** (eine Stelle, additiv). Neuer `CatalogStyleNormalizer.normalize(_:style:collectionName:)`: bei `.anthology` jede Folge `kind = .special`, fehlender/leerer Slug wird über `SpecialEpisodeSlug.make(...)` synthetisiert (bestehende Slugs werden **nie** überschrieben — eingefroren); bei `.numbered` unverändert. Aufruf direkt nach `parseNormalizedCatalogDocument`, **vor** `CatalogSnapshot`-Bildung, damit `specialSlugs` und Delta stimmen. Manuelle/eigene Kataloge haben keinen Manifest-Stil → bleiben `.numbered`. Gegenstück zu `reconcileCatalogStyles` auf Eintragsebene.
- **Generische „Originalquelle öffnen"-Aktion.** Reservierter Link-Key `"source"` (kein `StreamingService`-Case; `StreamingService(rawValue: "source")` bleibt `nil`). `CatalogEntry.links` speichert beliebige Keys bereits — kein Modell-/Backup-Format-Change. Resolver-Fallback: löst kein Streaming-Dienst auf und `entry.sourceURL != nil` → `(url, "Originalquelle öffnen", neutrales SF-Symbol)`. Detailansicht: `resolvedStreamingLink` → `resolvedExternalLink`, Tupel trägt den Symbolnamen. Neuer xcstrings-Key `Streaming.OpenOriginalSource` **mit `de` und `en`** ([[feedback_xcstrings_english_check]]); FR-Wert kommt in Paket 5.

### Abnahme (Prüf-Spalte Paket 2b)

`CatalogStyleReconcilerTests` (bzw. neue `CatalogStyleNormalizerTests`); Detail-Link-Ansicht; Statistik/Widget/Smart-List mit Anthologie-Fixture (Regressionsprüfung — diese Flächen prüfen bereits `usesEpisodeNumbers`). Zwei aufeinanderfolgende Refreshes desselben Anthologie-Katalogs: identische Slugs, kein Schein-Delta.
