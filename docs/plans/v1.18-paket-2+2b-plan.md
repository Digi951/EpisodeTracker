## Commit C — Paket 2.5: Coalescing + gedrosselter Vordergrund-Refresh

**`EpisodeTracker/Features/Catalog/EpisodeCatalog.swift`**

- `private var inFlightRefresh: Task<CatalogRefreshOutcome, Never>?`
- `refreshManagedCatalogsIfNeeded` umbauen: Kern in `private func performRefresh(force:ignoringThrottle:) async -> CatalogRefreshOutcome`; die öffentliche Methode:
  ```swift
  @discardableResult
  func refreshManagedCatalogsIfNeeded(force: Bool = false, ignoringThrottle: Bool = false) async -> CatalogRefreshOutcome {
      if !force, let inFlightRefresh { return await inFlightRefresh.value }
      let task = Task { await performRefresh(force: force, ignoringThrottle: ignoringThrottle) }
      inFlightRefresh = task
      let outcome = await task.value
      inFlightRefresh = nil
      return outcome
  }
  ```
  `force: true` (manueller Pull-to-Refresh) umgeht das Coalescing bewusst. `@MainActor`-Isolation macht `inFlightRefresh`-Zugriffe rennfrei.

**`EpisodeTracker/Shared/App/EpisodeTrackerApp.swift`**

- `.onChange(of: scenePhase)` erweitern:

  ```swift
  .onChange(of: scenePhase) { oldPhase, newPhase in
      if newPhase == .active {

              Task { await EpisodeCatalog.shared.refreshManagedCatalogsIfNeeded() }   // kein ignoringThrottle
          }
      }
  }
  ```
  Einfacher: ein `@State private var didRunInitialCatalogRefresh = false`; im `.task` nach `bootstrap` auf `true` setzen; im `onChange` nur refreshen, wenn `didRunInitialCatalogRefresh`. Kein Doppel-Fetch beim Kaltstart, `shouldRefresh` (6 h) drosselt die Folgeaktivierungen.

```swift
enum CatalogStyleNormalizer {
    /// anthology ⇒ jede Folge .special mit stabilem Slug; numbered ⇒ unverändert.
    static func normalize(_ entries: [CatalogEntry], style: CatalogStyle, collectionName: String) -> [CatalogEntry] {
        guard style == .anthology else { return entries }
        let universeKey = CatalogLibraryMatcher.normalizedCollectionKey(collectionName)

                                collectionName: entry.collectionName, links: entry.links)
        }
    }
}
```
